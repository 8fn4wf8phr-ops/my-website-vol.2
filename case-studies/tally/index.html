Tally

A privacy-first native iOS app for reminders to take medication or stick to a daily routine — no accounts, no cloud sync, nothing leaves the device.

Capacitor Vite iOS Vanilla JS

Overview

Tally is a native iOS app for reminders to take medication or stick to a daily routine — no accounts, no cloud sync, nothing leaves the device. Built with Capacitor wrapping a vanilla HTML/CSS/JS app.

The Challenge

Most reminder apps require an account before adding a single reminder, which felt wrong for health-adjacent data. The bar was: simple, offline, private. Scope had to stay narrow — add/edit/delete a reminder, local notification, mark it taken — resisting the urge to add dosage tracking, history, or streaks in v1.

The Approach

Chose Capacitor over learning React Native, since it let existing HTML/CSS/JS skills wrap into a real native app. Kept state simple — a "taken" status is just a stored date string compared to today, resetting automatically with no scheduled job. Built and smoke-tested the whole app in-browser before touching Xcode. Went from web app to native via Vite bundling, npx cap add ios, and building/signing from Xcode directly on a local machine. Refined visuals with an electric-teal accent, animated title mark, glow-and-press button effects, and a bouncy check-off animation.

The Result

Runs successfully in the iOS Simulator via Xcode — a working native, privacy-first app ready for real-device testing and eventual App Store submission.

What I'd Change Next

  • Test on a real phone
  • Design an app icon and launch screen
  • Polish the notification permission flow
  • Consider multiple reminder times per day
  • Add a weekly view
  • Add a streak feature with a grace period
