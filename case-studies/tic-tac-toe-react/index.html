Tic-Tac-Toe (React)

A React rebuild of an earlier vanilla-JS Tic-Tac-Toe game, built specifically to learn React hands-on after asking "what is React."

React 19 Vite Vercel

Overview

A React rebuild of an earlier vanilla-JS Tic-Tac-Toe game, built specifically to learn React hands-on after asking "what is React."

The Challenge

Going from a vanilla JS implementation to React meant re-thinking the same game (2-player + unbeatable minimax AI, dark mode) through components and state, while also setting up a full toolchain (Node.js, Vite, Git, GitHub, Vercel deploys) for the first time.

The Approach

Scaffolded with Vite and React 19, installed Node.js from scratch, and rebuilt the game with the classic React tutorial feature of a move-history/time-travel list. After the initial rebuild, expanded well past parity with the original: fill/win animations, sound effects with a mute toggle, win confetti, full keyboard support (arrow keys, Enter, number keys 1-9), selectable AI difficulty levels, a rematch button that alternates who moves first, an undo button, and Open Graph meta tags for link previews. Connected the GitHub repo to Vercel for automatic redeploys on push.

The Result

A fully-featured, polished React app live on Vercel with analytics enabled, going well beyond the original scope as a genuine learning-to-shipping project.

What I'd Change Next

  • Online multiplayer mode
  • A larger board size variant

That said, the project already serves its purpose as a complete React learning exercise.
