Weather App

Live city search with autocomplete, geolocation lookup, current conditions, and a 5-day forecast.

Live Demo GitHub
[ preview ]

Overview

A weather app that surfaces current conditions and a 5-day forecast for any city, with live search-as-you-type autocomplete and a one-tap geolocation lookup for wherever you are. It's powered by a free weather API that requires no API key to use.

Challenges

Autocomplete search needed debouncing so it wasn't firing an API call on every keystroke — waiting for a short pause in typing before querying kept the app responsive without hammering the API. Handling ambiguous city names, which are often shared across multiple countries, meant surfacing enough context (country, region) in the suggestion list for people to confidently pick the right one.

Features

  • Live city search with debounced autocomplete
  • Geolocation-based lookup
  • Current conditions at a glance
  • 5-day forecast
  • Disambiguation for cities sharing a name
  • No API key required

Tech stack

  • CoreJavaScript
  • DataWeather API
  • PatternDebounced search
  • HostingVercel
