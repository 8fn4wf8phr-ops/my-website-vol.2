Calculator

Overview

A calculator app that goes beyond basic arithmetic — it includes a scientific mode, a built-in unit converter, and a searchable history of past calculations that can be exported to CSV. It's built to be installed as a Progressive Web App and used fully offline.

Challenges

Keeping scientific and standard modes on one shared expression-parsing engine, rather than two bolted-together calculators, meant designing the parser to handle both simple arithmetic and more complex scientific functions through the same code path. Making it installable as a PWA also meant handling offline caching properly for a tool that, by nature, shouldn't need network access at all to function.

Features

  • Standard and scientific calculator modes
  • Built-in unit converter
  • Calculation history with search
  • CSV export of calculation history
  • Installable, offline-capable PWA
  • Local storage persistence between sessions
