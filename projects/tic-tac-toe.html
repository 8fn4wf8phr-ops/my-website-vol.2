Tic-Tac-Toe (React)

A React + Vite rebuild of the classic game, with an unbeatable minimax AI and selectable difficulty.

Live Demo GitHub

Overview

A rebuild of the classic tic-tac-toe game using React and Vite. It supports both 2-player local play and a single-player mode against an AI opponent, with a clean interface, move history, and full keyboard support.

Challenges

The unbeatable AI mode uses a minimax algorithm, requiring game-tree evaluation rather than simple conditionals — the AI has to look ahead through possible move sequences to always play optimally. Getting selectable difficulty right was the harder part: making the AI deliberately imperfect on easier settings without it feeling random took real tuning, balancing how often it "misses" a winning move against how predictable that made it feel.

Features

  • 2-player and single-player (vs. AI) modes
  • Unbeatable AI powered by minimax game-tree search
  • Selectable AI difficulty levels
  • Full move history with the ability to step back through a game
  • Keyboard controls for accessible play
  • Dark mode

Tech stack

  • FrameworkReact
  • Build toolVite
  • LogicMinimax AI
  • HostingVercel
